# failure-recovery —— 失败恢复与续做指针

> 任何一步卡住、报错、被打断时按本文处置。原则：**先定位层，再修；修不动就降级，别硬撑。**

## 1. 按校验层定位

| 报错层 | 典型症状 | 处置 |
|---|---|---|
| L1 结构 | XML 解析失败 / 缺 construction / expression 后没跟 element | 先 `xmllint --noout` 定位行号；对照金标准 §4 形态重写该块 |
| L2 引用 | label 重复 / 引用未定义对象 / 未定义标识符 | 全文搜索该 label；拼写、大小写、下标写法（`B_{1}`）逐一核对 |
| L3 拓扑 | 先用后定义 / 循环依赖 | 把被引用对象移到引用者之前；循环依赖说明设计错了，回 design.md |
| L4 数值 | 缓存与公式不符 / 缺缓存值 | 跑 `--fix`；仍不符说明 exp 写错（先信公式直觉再怀疑求值器） |
| L5 JS | node --check 报错 | 按 JS 报错行号修；修不好就把逻辑降级回 ggb 命令脚本 |

## 2. 高频故障速查

1. **GeoGebra 打不开产物** → 大概率 L1/L2 有漏网形态。用本机 GeoGebra 打开看具体弹窗；
   对照真实同型对象的 XML 逐块比对。
2. **画面空白/对象不见**：结构合法但视觉错——查 `<show object>`、`<layer>`、coordSystem 范围、
   absoluteScreenLocation/labelOffset 是否超出画布。这类 check 抓不到（无视觉闭环），靠打开验证。
3. **动画不动**：播放按钮的 `StartAnimation[t, true]` 是否执行？`t` 滑杆 animation 的 speed/type 是否配置？按钮脚本是否先 `SetValue[t, 0]` 归零？（标准初始态 `playing=false`，动画由按钮启动，不依赖滑杆自播）
   `type` 是不是 3（递增一次就停）？按钮脚本里引号转义对不对？
   点按钮弹「未定义变量」→ 脚本引用了不存在的变量（典型：`v = If[v,...]` 而文件里没有 v）
   → 先定义隐藏布尔自由对象再引用（金标准 §10 坑11）。
4. **数值看着不对**：三角函数弧度/角度混淆（金标准 §10 坑3）；物理公式本身错了回 design.md。
5. **中文乱码**：文件必须 UTF-8 无 BOM。

## 3. 会话续做指针

被打断后恢复工作的顺序：

1. 读 `projects/<课件名>/design.md`——规划与进度的事实源。
2. 跑 `ggb_check.py projects/<课件名>/geogebra.xml` 看当前状态（绿=可继续 Builder/打包）。
3. 若 XML 半成品：以 design.md 为准补完；design.md 也缺 → 从 exports/ 里找最近 .ggb 反推，
   或问用户要原始需求。
4. Modify 场景：工作目录 `projects/<课件名>-modify/` 就是现场，解包即续。

## 4. 降级路径

- **JS 写不出来/调试不动** → 回 ggb 命令脚本方案（命令优先原则本来如此）。
- **某对象怎么都过不了 L4** → 把它的表达式改写成求值器子集内的等价形式；或删缓存值留空，
  靠 GeoGebra 重算（note 不阻塞）。
- **复杂系统表达不了**（手写积分递推：JS/Sequence 循环）→ 物理真实性红线，直接告知用户超范围；内置 `NSolveODE` 许可，先试用再换解析近似方案
  或放弃该题材，不要造假运动规律。
- **确认门用户不在** → 交互会话：停在确认门前，把 design.md 摘要留在回复里等待；自主会话
  （无人在场、需求已完整明确）：按 quick 规则跳过并在 design.md 标注决策后继续
  （与 generate-ggb §4 自主会话规则一致，2026-08-30 修订）。

## 5. 已知边界（不是 bug）

- `Area/Distance/Polygon` 等内核命令算不了缓存值 → note「子集外」，GeoGebra 加载重算兜底。
- 含 `NSolveODE` 的文件属许可范围；check 对其导数变量跳过引用检查（note），其余照常校验。
- `--fix` 用 ElementTree 规范化重写 XML（缩进统一、`/>` 带空格）；语义不变，逐字符 diff 会变。
- 求值器函数子集清单见金标准 §9；新函数按实用个案例行扩展。
