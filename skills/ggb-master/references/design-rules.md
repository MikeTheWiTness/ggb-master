# design-rules —— 模拟课件设计规范

> 从实测返工中沉淀的设计规范。Planner 定参数域时、Builder 写公式前逐条对照；
> 违反本文档的问题多数能通过 ggb_check 的数值层暴露一部分，但**语义有效性靠流程自查**。

## 0. 物理量可视化规范（2026-08-27 用户宗旨）

| 情形 | 强制呈现 | 手法 |
|---|---|---|
| 演示运动 | 动点/物体**配速度矢量**（含大小箭头，随位置与方向实时更新） | 动点 M 的速度分量 vx/vy（分段闭式）→ `Vector(M, M+scale*(vx,vy))`；正交分解可另画 |
| 演示静力学 | **配力矢量图**（力的分解、合力/分力箭头，按比例尺） | 同上 Vector 链；力的大小/方向/分力读数为派生量 |
| 有磁场区域 | **场区标记**：匀场区排布 ⊗（垂直纸面向外）/ ⊙（向里）符号；磁感线（解析场线） | 文本对象摆放 ⊗/⊙ 阵（Sequence 生成），形状按场对称性严格解析 |
| 有电场区域 | **电场线/等势面**（解析优先） | 矢性函数 `E(x,y)=Σ kq/r²·r̂` 生成场强矢量阵（Sequence 点阵 × Vector）；等势线用隐式方程 `Φ=const` |
| 任意矢量场展示 | 形状**标准严谨**，优先**矢性函数/矢量场**呈现 | 禁止随手画示意线；场线族走解析特解，非解析流线（需积分）用内置 NSolveODE 近似并标注 |

执行细则：
- 速度/力矢量长度 = 物理量 × 统一比例尺（设计文档记录比例常数），方向跟随分段运动解析式；
- 场区标记用点阵而非单个符号（均匀覆盖、间距随画布缩放）；
- 场线解析特例速查：点电荷族（径向直线）、匀强场（平行直线族）、圆形匀强磁场（同心圆族）、点偶极子（解析曲线族）；
- `⊗/⊙` 用文本对象画（layer 0，随场区平移），避免近似美术符号；
- **Builder 自查**：design 确认时把本条列为必过项（「速度矢量✓ 场标记✓」写进 design.md 可视化小节）。

## 1. 模型有效域优先（红线级）

每个解析解都有**成立条件**。先写出条件，再谈滑杆范围；条件本身要写进 design.md 的「模型有效域」小节。

案例（弹簧双体，2026-08 实测返工）：SHM 解允许弹簧长 ℓ<0（物块互穿）——根因是
**滑杆参数域超出模型有效域**。教训：物理推导交给模型，但「有效域边界」必须在 design.md
「模型有效域」小节显式写出成立条件（红线级）。常见类型（模型按各题材自举）：

| 模型 | 解析解成立条件（示例） |
|---|---|
| 弹簧双体 | 弹簧长 ℓ(t) ≥ 几何最小间距 |
| 开普勒轨道 | 0 ≤ e < 1；级数解高 e 精度下降需说明 |
| 小角近似类 | θ ≪ 1 rad，课件标注「小角度」 |
| 抛体/触地类 | 落地即止，无反弹模型不画反弹 |
| 含分母/根号 | 分母 ≠ 0；被开方数 ≥ 0；asin/acos 定义域 |

## 2. 参数域 ⊆ 有效域：滑杆范围的推导法

滑杆 min/max 四步推导（纯数学方法，模型自行执行，此处只立流程）：

1. 有效域写成**不等式**（含几何余量）；2. 找**最坏参数组合**（耦合量按联合极值，不许
各自独立取极值）；3. 解不等式得滑杆下限/上限；4. 回填 design.md 滑杆表并在「模型有效域」
记录推导一行。收不住的按 §6 降级顺序处置。

## 3. 状态量非负性 / 可行性清单（Builder 自查）

ggb_check 只保证「缓存值 = 公式」，**公式本身的语义有效性靠自检**（模型逐条过）：

- [ ] 长度 / 间距 / 半径 > 0；质量 / 时间 / 能量 / 面积 ≥ 0
- [ ] 角度在定义域（asin/acos [-1,1] 等）；分母不为零；被开方数 ≥ 0
- [ ] 事件顺序可行（「未碰撞则间距不为负」「落地后不再下落」）

任一条在滑杆极值下可能被打破 → 回到 §2 收参数域，或按 §6 处置。

## 4. 守恒量写成恒等式校验

动量/能量/电荷等守恒量，**不要只算一份**：写成两条独立表达式链并排显示
（如 `pTotal = m1*v10+m2*v20` 与 `pNow = m1*u1+m2*u2`）。
这样 ggb_check 第四层在加载初态就自动验证两者相等（t=0 时还顺带验证
u₁(0)=v₁₀、u₂(0)=v₂₀ 的初值编码正确性）。守恒被破坏会直接变成缓存不一致报错。
- ⚠ **对拍独立性（2026-08 环形磁场返工教训）**：两条链（或独立模拟与闭式解）必须**独立推导**——
  共享同一错误假设时，误差会被互相掩盖（实例：对照双方同错、位错被掩 2 m）。
  自检链路的独立性本身也是自检项。

## 5. 显示钳制的合规边界

- **允许**：纯显示层面的钳制，物理事实不变。
  例：平抛 `tt=min(t,T)` 落地后停住（小球本来就停在地面）；
  `If[t<T, …, 终态]` 切换终态显示。
- **不允许**：为了掩盖有效域违规而篡改运动规律。
  例：弹簧长要变负时强行反转速度——那是「有接触/碰撞模型」的行为，
  属事件驱动分段解析，超出当前课件声明的模型范围；要么收参数域，要么明说换了模型。

## 5.5 动画节奏合规（无初等时间解的摆动类系统）

悬点可动单摆类系统（摆的悬点可沿光滑约束移动）φ(t) 无初等解（椭圆积分）。诚实做法（2026-08-30 实测定型）：
- 主时钟驱动**自然参数**（摆角 q），每帧位置与速度矢量由守恒律闭式给出——逐帧状态精确；
- design.md 与 说明.md 双声明「摆动段按摆角匀速扫过，时间为演示节奏」；
- NSolveODE 换自变量链（dw/dq、dt/dq）解出**真实时长 t₁**上屏，补偿节奏失真的信息量。

禁止：匀角速近似状态（状态假 = 造假红线）；不加声明的静默节奏失真。有初等时间解的段
（抛体、自由飞行等）仍按真实时间驱动。

## 6. 参数域实在收不住时的降级顺序

1. **收紧滑杆范围**（首选，零成本零风险）；
2. 缩小几何尺寸/改常量（如加大 L₀、缩小物块宽）再收一次；
3. 画面显式警示：派生布尔 `warn = ℓ < margin` + 文本对象
   `If[warn, "⚠ 当前参数超出模型适用域…", ""]`，并在 caption 里解释原因；
4. 换模型或放弃该题材（物理真实性红线优先于演示效果）。

## 7. 流程挂钩

- **Planner**：design.md 必须有「模型有效域」小节（模板自带），
  确认门摘要里向用户提一句适用域边界。
- **Builder**：写滑杆 `<slider min max>` 前完成 §2 推导；写完公式过一遍 §3 清单。
- **Reviewer（用户打开验证时）**：把每根滑杆拖到两头看一眼——
  极值处不出鬼，才叫参数域收住了。
