# export-html-demo —— 可选出口：单文件 HTML 定妆演示件

> 产出一个**免环境、零外部依赖、可嵌入网页/PPT** 的单文件 HTML，播放本课件**最核心的一次
> 动态演化**（默认参数组下、实现探究目标结论的那一遍）。这是 .ggb 交互件的**播放器形态补充**，
> 不是替代：参数探索归 .ggb，HTML 只负责把结论过程干净地放一遍。
> **公式自推声明（SKILL.md 第 0 条）**：物理推导与轨迹计算由项目侧 Python oracle 负责，
> 本文档只定纪律、数据契约与工具形态。

## 0. 触发与定位

- **触发**：用户明确要「免 GeoGebra 环境的版本」「能发给别人直接看的」「可嵌网页的演示」。
  不默认执行；Generate 主流程（generate-ggb.md）完成并通过视觉验收后才走本步。
- **产物**：`exports/<课件名>-演示.html` —— 单文件（模板 + 内联数据），断网可演，无构建步骤。
- **定位声明（写进产物页脚与项目说明.md）**：定妆演示件为**单过程只读播放**；改参数探索请用
  同目录 .ggb。禁止把 HTML 往参数化模拟器方向演化（那会制造物理公式的第二份前端拷贝，
  破坏「真源唯一」纪律）。

## 1. 三条纪律（红线）

1. **只播放不模拟**：模板 JS 中禁止出现任何物理公式、积分器、分段逻辑；一切数值来自
   内联数据。播放器只做：插值、画图元、时间轴。
   （例外，2026-09-16 定：用户明确要求交互调参的演示件可含 JS 闭式解，但必须以
   oracle 网格对拍为真源校验——bake 用项目 verify 算网格真值嵌入 data，HTML 加载时
   逐点对拍、偏差控制台即时报错；参考 2025北京丰台区期中 项目。）
2. **真源唯一**：数据由项目侧 `bake_html.py`（模型写）生成，它必须 **import 项目 verify
   推导**（同一份闭式解/常数），禁止在 bake 里手抄第二遍公式。对拍恒等式沿用 verify 的。
3. **真实时间**：关键帧的 `t` 是物理时间（秒），播放按 t 驱动线性插值——无初等解段
   （悬点可动单摆类等，见 design-rules §5.5）由 Python 数值采样，**HTML 版不受 GGB 滑块
   节奏限制**，摆动段也按真实时间播放。允许的只有全局倍速按钮（0.5×/1×/2×）。

## 2. 数据契约（schema v1）

bake 产出 `data.json`，拼装时内联进 HTML 的 `<script id="demo-data" type="application/json">`。
所有坐标为世界坐标（米），y 轴向上；播放器显示窗口固定 960×620，**等比映射**：bbox 外扩
8% 后，不足的维度按显示宽高比居中补齐（保证 x/y 每米像素数一致，几何与标注比例不失真）。

```jsonc
{
  "meta": {
    "title": "课件标题",
    "conclusion": "一句话结论（含关键数值）",
    "params": {"k": 1.5, "v0": 8.0},          // 默认参数组，仅展示
    "footer": "定妆演示件 · 参数探索请用同名 .ggb"   // 可选
  },
  "scene": {
    "bbox": [xmin, ymin, xmax, ymax],
    "shapes": [                                // 静态背景，按序绘制
      {"type": "polygon", "pts": [[x,y],...], "fill": "#ecd8c0", "stroke": "#96805a", "alpha": 0.5},
      {"type": "segment", "a": [x,y], "b": [x,y], "color": "#464650", "width": 4, "dash": false},
      {"type": "label",   "pos": [x,y], "text": "A", "color": "#0050b0", "size": 16},
      {"type": "point",   "pos": [x,y], "color": "#0066cc", "size": 5}
    ]
  },
  "actors": [                                  // 1..n 个动点（质点类主体）
    {"id": "主体1", "color": "#cc0000", "size": 8, "trail": true, "vector": true}
  ],
  "links": [                                   // 动体间连接线（绳/杆等约束的视觉呈现），可选
    {"a": 0, "b": 1, "color": "#50505a", "width": 3, "until_t": 0.76}   // until_t 省略=全程可见
  ],
  "frames": [                                  // 关键帧，t 严格单调递增（秒），≥2 帧
    {"t": 0.00, "pos": [[x,y]], "vel": [[vx,vy]], "phase": "阶段一：约束段"},
    {"t": 0.85, "pos": [[x,y]], "vel": [[vx,vy]], "phase": "阶段二：自由段"}
  ],
  "marks": [ {"t": 0.76, "label": "事件名"} ],  // 事件章节，t 须落在帧范围内
  "readouts": [ {"label": "要求初速", "value": "7.98", "unit": "m/s"} ]
}
```

- `vel` 可省（省略则该帧不画矢量）；`phase` 可省（省略沿用上一帧）；`trail/vector` 默认 true。
- links 可选 `"spring": true`（锯齿弹簧纯视觉样式，配 `coils` 折数、`amp` 幅度，世界单位；
  2026-08-30 新增）。末刻度标签超 60px 会右溢出，模板已按 `:last-child` 右对齐加宽处理。
- 事件名用**通用过程词**（释放/脱离/触地/终态/回到起点…），不写具体题材故事。
- 体量参考：1000 帧 × 单动点 ≈ 100 KB，上限 2 MB（校验器强制）。
- 含公式的文本字段（meta.conclusion / meta.tip / readouts[].label 等）允许内嵌 `$...$`
  LaTeX 行内段，由模板按 §2.5 渲染为标准排版。

## 2.5 公式排版（LaTeX / KaTeX 内联）

- **要求（2026-09-16 定）**：演示件画面中的物理公式一律用 LaTeX 源串（`$...$` 内联标记）
  渲染为标准排版（KaTeX），**禁止用 Unicode 拼凑（√、下标字符、≤ 等）冒充公式**。
  适用位置：结论行、读数标签、提示行等一切含公式的文本。
- **断网可演红线**：禁止 CDN 引 MathJax/KaTeX；KaTeX 必须内联进单文件——katex.min.js +
  katex.min.css + **实际用到**的 woff2 字体（一般 KaTeX_Main-Regular 与 KaTeX_Math-Italic
  即覆盖行内公式；`\sqrt` 由 KaTeX 以 SVG 绘制、行内 `\frac` 不触发 Size 字体）。
  未用字体保留 katex.min.css 里的相对路径即可——浏览器不会请求未使用字体。
- **实现**：KaTeX 发行版 vendor 到项目 `vendor/katex/`（katex.min.js / katex.min.css /
  字体）；bake 拼装时替换占位符 `__KATEX_JS__` / `__KATEX_CSS__`；CSS 在 katex.min.css
  之后追加同名 @font-face 覆盖（`data:font/woff2;base64,…`）。模板提供 `$...$` 解析渲染
  函数（katex.renderToString，try/catch 失败回退纯文本）。KaTeX v0.16.21 实测体积：
  JS 277 KB + CSS 23 KB + 两字体 base64 ≈ 57 KB → 单文件 +~360 KB，产物上限放行 6 MB。
- **校验器注意**：外部引用判定必须按真实网络引用（`<script src>`、`<link href>`、
  `url(http`、`fetch("…")`、`@import`）；katex.min.js 内部的 parser.fetch() 方法与
  `img.src` 字段是误报源（2026-09-16 实测），粗判 `src=` / `fetch(` 会拦掉合法产物。
- **正常现象勿误判**：KaTeX 输出的 .katex 元素含隐藏 MathML 与 `<annotation>` 原文，
  textContent 会呈现「渲染文本 + 原始 LaTeX + MathML」拼接——无障碍输出，不是重复渲染。

## 3. 流程（五步）

1. **前置**：Generate 主流程已完成、五层校验与视觉验收通过；项目内有 verify 推导
   （无则先补——本步不允许在无 oracle 的项目上执行）。
2. **bake**（模型写 `projects/<课件名>/bake_html.py`）：先跑 `verify.self_check()`——
   逐帧能量/动量断言不过**不 bake**（实测：势能符号错误被逐帧断言当场拦截）；再
   import verify → 闭式段直算、无初等解段定步长 RK4 采样（步长取总时长/1000 左右）→
   按契约产出 `data.json`；关键量（终态位置、事件时刻）与 verify 的预期值断言一致。
3. **校验**：`python3 scripts/html_demo_check.py projects/<课件名>/data.json` → 0 error。
   （schema v1 的 2D 定妆件必须 0 error；3D/交互变体用各自 bake 内嵌 validate 校验 schema，
   共享校验器只保证外部引用/体积/占位符检查——schema 报错属预期，不算不通过。）
4. **拼装**：模板占位符 `__DATA__` 替换为 data.json 文本（`</` 转义为 `<\/`）；含公式的
   演示件一并内联 KaTeX（`__KATEX_JS__` / `__KATEX_CSS__`，见 §2.5）→
   `exports/<课件名>-演示.html` → 再跑 `html_demo_check.py <该html>`（二次校验内联数据 +
   外部引用扫描 + 体积）。
5. **视觉验收**：本地浏览器打开截图（初态/中段/终态 + 章节跳转），检查清单沿用
   generate-ggb §9.3；通过后项目说明.md 补一行（产物名、双击即开、定位声明）。
   截图批次的**每一张**都必须显式 seek 到声明时刻（含 t=0 初态与终态；终态之后再拍初态
   必须显式归零）——漏写会拍到上一状态，2026-08-30 实测被 judge 判「状态错位」返工一轮。

## 4. 播放器模板（scripts/html_demo/template.html）

- **原生 JS、零外部依赖**（不引 CDN、无字体/图片外链），占位符 `__DATA__`；含公式的
  演示件另需 `__KATEX_JS__` / `__KATEX_CSS__`（§2.5，共享 2D 模板未内置，项目模板自行加，
  参考 2025北京丰台区期中/template3d.html）。
- 功能：**打开不播、一点即播**（与 interactivity §3 教训一致）；播放 / 暂停 / 重播 /
  倍速（0.5×/1×/2×）；进度条（含事件章节刻度，可点击跳转）；阶段标签与结论读数常驻；
  结束定格末帧。
- 渲染元素与契约一一对应：scene.shapes（静态）→ actors（点/轨迹/矢量）→ readouts/meta。
- 改模板属 Modify：先改 skill 内模板（两份副本同步），再重拼装各项目产物。

## 5. JS/TS 判定（"根据情况选择"的落点）

冻结的单文件播放器用**原生 JavaScript 免构建**——引入 TS 构建链对一次性内联产物只添乱。
仅当未来出现「参数化导出器」「多模板工程」等需要类型与模块化的场景，才把**工具链**升级 TS；
播放器本体与数据契约保持不变。

## 6. 常见坑

1. 数据内联未转义 `</` → 提前终止 script 标签（bake 侧统一 `</` → `<\/`）。
2. **画布映射各向异性**：x/y 每米像素数不一致会让几何与自身标注矛盾（绳长画得比更长的
   线段还短、角度走样；2026-08-30 实测，5 帧全数 fail 的根因）。映射必须等比，按显示
   宽高比补齐世界窗口，禁止分别用 bbox 两维独立铺满画布。
3. bbox 未留边距 → 标签/矢量出画布（映射函数按 bbox 外扩 8% 计算）。
4. 关键帧采样过疏 → 高速段折线感明显；采样密度以「相邻帧位移 ≤ bbox 对角线 1%」为准。
5. 矢量比例尺硬编码 → 换参数组后箭头出画布；比例尺由 bake 按最大速率与 bbox 对角线算好，
   作为 `meta.vecScale` 下发，播放器只乘不算。
6. 拼装后没跑第二遍校验 → 外部引用/超限漏检（流程第 4 步的两次校验缺一不可）。
7. **静态标注压在轨迹带上**：标注初看无碰撞，但动体会扫过整条轨迹——任何落在轨迹覆盖区
   （含事件瞬间的动体占位）的标签都会在某一帧被压（2026-08-30 实测：标签被释放帧动点压住，
   挪到同侧空区仍中招）。对全部关键帧的动体/轨迹带检查标注位置；避不开就移入大片留白区。
8. **时间轴刻度标签压进播放头运动带**：播放头停在章节刻度处时圆点盖住标签字（2026-08-30
   实测两帧中招）。刻度线与标签整体放在进度条滑块区之外，末刻度标签右对齐防溢出。
9. 公式用 Unicode 拼凑（√、下标字符、≤）冒充排版 → 观感差且易错；一律 `$...$` + KaTeX（§2.5）。
10. 为省事用 CDN 引 MathJax/KaTeX → 破坏断网可演，且被外部引用校验拦截；必须内联（§2.5）。
11. 外部引用按 `src=` / `fetch(` 粗判 → katex.min.js 的 parser.fetch()/img.src 误报；
    按 §2.5 的真实网络引用模式判定（html_demo_check.py 已按此更新，2026-09-16）。
12. 把 katex 全部 ~66 个 @font-face 的字体全 base64 → 文件膨胀 2 MB+ 且大半永不使用；
    只内联实际用到的字体（Main-Regular / Math-Italic 一般足够）。
13. 内联 KaTeX `<script>` 前未查 `</script` → 提前终止脚本；拼装前 grep 确认 0 次。
