# 直抄片段：正电荷（源：宏库 .ggt）

- 用途：选择一点
- 输入 1 个 → 输出 1 个（输出对象按需保留/隐藏）。
- 已知坑：原宏用 PointIn 随机点，每次导入外观不同；本片段已确定性化（Point[路径, 0.5]）。
- **多片段同用时**：把下面的 `zdh_` 全局替换为你项目内的唯一前缀，防标签冲突。
- 输入对象：片段自带输入定义（label 带 `zdh_` 前缀）；替换 label 时同步替换片段内引用。

## XML 片段（贴进 <construction> 末尾）

```xml
<element type="point" label="zdh_A"><show object="true" label="false" ev="4" /><objColor r="77" g="77" b="255" alpha="0" /><layer val="2" /><labelMode val="0" /><animation step="1" speed="1" type="1" playing="false" /><pointSize val="6" /><pointStyle val="0" /><coords x="1.9833215603808678" y="2.507927614208072" z="1" /></element>
<expression label="zdh_L_1" exp="{Circle[zdh_A, 0.25], Sequence[Segment[Point[Circle[zdh_A, 0.25], t], Point[Circle[zdh_A, 0.25], t + 1 / 2]], t, 0, 1 / 2, 1 / 4]}" />
<element type="list" label="zdh_L_1"><show object="true" label="false" ev="4" /><objColor r="0" g="0" b="0" alpha="0" /><layer val="2" /><labelMode val="0" /><lineStyle thickness="5" type="0" typeHidden="1" /><pointSize val="7" /><pointStyle val="0" /><angleStyle val="0" /></element>
```

## 取用步骤

1. 把 XML 片段贴进目标 geogebra.xml 的 `</construction>` 之前。
2. 若与其它片段共用，先全局替换 `zdh_` 为唯一前缀。
3. 跑 `ggb_check.py <项目>/geogebra.xml --fix` 填缓存；再 `ggb_pack.py` 打包。
