# 直抄片段：半圆槽（源：宏库 .ggt）

- 用途：半圆槽
- 输入 2 个 → 输出 8 个（输出对象按需保留/隐藏）。
- 已知坑：原宏用 PointIn 随机点，每次导入外观不同；本片段已确定性化（Point[路径, 0.5]）。
- **多片段同用时**：把下面的 `byc_` 全局替换为你项目内的唯一前缀，防标签冲突。
- 输入对象：片段自带输入定义（label 带 `byc_` 前缀）；替换 label 时同步替换片段内引用。

## 取用步骤

1. 把 XML 片段贴进目标 geogebra.xml 的 `</construction>` 之前。
2. 若与其它片段共用，先全局替换 `byc_` 为唯一前缀。
3. 跑 `ggb_check.py <项目>/geogebra.xml --fix` 填缓存；再 `ggb_pack.py` 打包。
