# 宏工具库（自定义工具）：.ggt + 直抄片段库（2026-08 双轨制）

> 上线原则（SKILL.md 第 0 条）：取用成本 ≤1 次读取。标准画法元件的首选形态是
> **`macros/snippets/` 直抄片段**（markdown + 已验证 XML：零拆包、确定性、可被
> ggb_check 校验）；`.ggt` 保留为「按需导入 GeoGebra 工具」的备选通道。
> 任何宏先用 `ggb_macro_preview.py` 预览定夺（含自包含审计），禁止未经预览拆包细读。

## 决策表（1 次读取定夺）

| 元件类型 | 取用方式 |
|---|---|
| 电路符号（电阻/开关/电源/表盘/变压器…） | `snippets/circuit/` 直抄；缺的查全表 |
| 力学家具（滑轮/小车/弹簧/物块/凹槽…） | `snippets/mechanics/` 直抄 |
| 坐标纸/数轴、正负电荷 | `snippets/misc/`、`snippets/field/` 直抄 |
| 简单几何（垂线/定长直线/箭头/区间…） | **手绘**（命令数 ≤4 一律手绘更省） |
| 全表 ⚠ 残缺宏 | **不用**（自包含审计失败，导入 GeoGebra 同样失败，见「质量审计」） |
| 其余 .ggt | 预览定夺：有 ✂ 用片段；无 ✂ 按需调用 .ggt |

> **多版本与冲突（同名族取舍）**：
> - 以下 13 组 toolName 重复，同一项目只并入一个（后并者静默覆盖前者）：电阻箱×3；
>   定值电阻/定值电阻_v2（均 R）、电流表、电压表、电感、电容器、开关、光敏电阻、二极管、
>   电阻、数轴、无限区间、有限区间（各 ×2）。
> - 取舍：有 ✂ 用片段；否则预览后取无 ⚠、签名符合需要的版本（如电源用 电源_v3，
>   电源/电源_v2 残缺仅存档）。
> - 宏内标签（A_2/S_3/V' 等）是源场景提取产物：并入项目前先查与主构造重名；
>   部分宏用 Corner[n] 依附当前视图定尺寸/定位（表盘、坐标轴、箭头类），
>   位置随你的视图而定——预览输出的「视图依附」行会提示。

## 使用

- **直抄片段**：`macros/snippets/<类>/<工具>.md`——贴进 `<construction>` 末尾，
  跑 `ggb_check.py --fix` 填缓存再 `ggb_pack.py` 打包；多片段同用先全局替换片段前缀。
- **.ggt 导入**：GeoGebra「工具 → 管理工具 → 打开」；或按 construction-language §4.13
  并入项目 `geogebra_macro.xml`。
- **预览/审计**：`python3 scripts/ggb_macro_preview.py <宏.ggt>`（1 次调用：签名、构造规模、
  随机点、自包含状态、直抄片段是否就绪）。
- **重新生成片段**：片段库由维护流程从 .ggt 批量生成并逐个自证（最小 test .ggb 过 ggb_check
  双重校验）；重建方法与转换规则见仓库维护文档（不随本 skill 分发）。
- **注意**：`接地` 等符号常用在电路语境但文件在 misc/；「工具名即命令名」不成立的特例：
  垂线段/强角/地面/变阻器三点的真实 cmdName 为 Tool63/Tool3/Tool4/Tool5（见上表别名列）。
